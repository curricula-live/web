# Checked logical reasoning on concept pages

The Boolean, truth-value, statement and condition pages show all six checked schemas. AND, OR and NOT pages show the schemas using their respective operator. The preview has an interactive Boolean truth table, numbered selectable propositions, linked inference steps, assumption contexts, discharge markers and inspectable certificates.

The artifact `lib/logic/checked-examples.json` is generated by the API Python kernel and is bundled so that the existing web development preview works before the companion API deployment updates. It is a library of closed schematic propositions, not a new canonical definition or a derivation from provisional graph edges. P and Q stand for arbitrary Boolean propositions. Numeric ≤, class inclusion ⊑ and propositional implication ⇒ retain distinct meanings.

Regenerate from matching API checkout:

```sh
python -m core.logical_reasoning > ../web/lib/logic/checked-examples.json
```

The natural-deduction kernel checks each rule and open assumption set. Its truth-table checker independently checks each closed conclusion. The web CI additionally checks fingerprints, previous-step references, every step's semantic entailment under its declared assumptions, every truth-table row, all closed goals and concept mappings with `node scripts/verify-logical-reasoning.mjs`.

The preview exposes AND introduction/elimination, OR introduction/elimination by cases, implication introduction/elimination, IFF introduction/elimination, NOT introduction/elimination and contradiction elimination in the kernel. Visible examples cover conjunction commutativity, disjunction commutativity, modus ponens, derived modus tollens, one De Morgan implication and extracting an implication from an explicit biconditional.

The API companion also exposes `GET /v1/concepts/{slug}/logical-reasoning/`; it requires an existing supported concept and serves only the fixed checked library, never user-submitted proofs. No canonical database migration or publication is needed.
